# Offline English dictionary

These are the unchanged en_US.aff and en_US.dic assets shipped by
codemirror-spell-checker 1.1.2. The old plugin is no longer installed. Keeping
its dictionary preserves spelling behavior, including accented words, while
the CodeMirror 6 view plugin uses Typo.js directly. Decode both as ISO-8859-1.

Source: https://registry.npmjs.org/codemirror-spell-checker/1.1.2

The published package's LICENSE is retained here and copied into desktop
artifacts. The original dictionary files are not modified or regenerated.
